#This pipeline is how the metagenomes were quality assessed, trimmed, assembled, binned, and analyzed. This is not for the virome analyses. 

#SUMMARY of pipeline
After sequencing metagenomes from a sequencing platform such as illumina, the metagenome reads was assessed for good quality via FastQC (0.12.1) and trimmed using trimmomatic (0.39). Unwanted sequencing information such as adapters was removed using trimmomatic and host DNA was removed via kneaddata, which is specifically used for metagenome data. Pair end reads were specified in the trimmomatic script to trim both forward and reverse reads. The metagenomes were assembled using MetaSPAdes (4.0.0) and quality assessed with MetaQuast (5.0.2), genome binning and refinement with metaWrap. Bin quality was assessed with Checkm2 (1.0.1) and genomes were dereplicated using dREP (3.5.0). Metagenomes were analyzed for taxonomy using gtdbtk, genome annotations such as proteins present using prokka (1.14.5), and metabolic capabilities using DRAM (1.4.6).

### Adapter Trimming (Trimmomatic)

Why trim?
■ Remove adapters
■ Remove low-quality bases
■ Remove short reads

```bash
module avail trimmomatic
module load trimmomatic/0.39
java -jar $trimmomatic -h #Palmetto the module does not put trimmomatic-0.39.jar in your current folder. Instead, it sets an environment variable pointing to the jar so change the calling in default settings;java -jar $trimmomatic -h 
cd /project/bcampb7/camplab/MICRO_8130_2026/metagenome_jojy/raw_data #no need to change
mkdir -p trimming_results
#on Palmetto2. please use
java -jar "$trimmomatic" PE \
  -threads 8 \
  -phred33 \
  ABF4_143_1.fastq \
  ABF4_143_2.fastq \
  ABF4_143_1_paired.fastq.gz \
  ABF4_143_1_unpaired.fastq.gz \
  ABF4_143_2_paired.fastq.gz \
  ABF4_143_2_unpaired.fastq.gz \
  ILLUMINACLIP:TruSeq3-PE.fa:2:30:10:2:True \
  LEADING:3 \
  TRAILING:3 \
  SLIDINGWINDOW:4:15 \
  MINLEN:36 \
  2> ABF4_143_trimmomatic.log

● KneadData 
KneadData is specifically designed for metagenomic data and integrates multiple tools.

```bash
mkdir -p decontaminated
mkdir -p logs/kneaddata

# Single sample
kneaddata \
    --input trimmed/sample1_R1_paired.fastq.gz \
    --input trimmed/sample1_R2_paired.fastq.gz \
    --output decontaminated/sample1 \
    --reference-db /path/to/databases/kneaddata_db/human_genome \
    --threads 16 \
    --trimmomatic /path/to/trimmomatic \
    --bypass-trim \
    --log logs/kneaddata/sample1.log

# Options:
# --bypass-trim : Skip trimming (already done with Trimmomatic)
# --reference-db : Path to host genome database
# --threads : Number of threads

##### Genome annotations
module avail prokka
module load prokka/1.14.5
mkdir -p prokka_out

for g in *.fa 2>/dev/null; do
  [ -e "$g" ] || continue
  sample=$(basename "$g")
  sample=${sample%.*}

  prokka \
    --outdir "prokka_out/${sample}" \
    --prefix "${sample}" \
    --cpus 8 \
    --kingdom Bacteria \
    "$g"
done
