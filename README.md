# Soil-virome-analyses
Soil environments are known to harbor abundant and diverse bacterial communities, but less attention has been given to the role of non-living biological entities such as viruses in shaping soil microbial diversity. The code in this directory focuses on assembling soil viral contigs from soil metagenomic datasets and analyzing the environmental variables that influence soil virome communities. In addition, soil microbial metagenomes were examined for auxiliary metabolic genes (AMGs) using a bioinformatics-based approach. This workflow incorporates several virome analysis tools, including VirSorter, VITAP, geNomad, DRAM-v, and other bioinformatics pipelines to characterize soil viral communities and their ecological functions.
