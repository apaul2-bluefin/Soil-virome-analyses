# Soil-virome-analyses
Soil environments harbor abundant and diverse bacterial communities, yet the role of viruses in shaping soil microbial diversity remains less explored. The scripts in this directory assemble soil viral contigs from metagenomic datasets and analyze environmental factors influencing soil virome communities. Soil microbial metagenomes were also examined for auxiliary metabolic genes (AMGs) using bioinformatics approaches. This workflow integrates tools such as VirSorter, VITAP, CheckM, geNomad, and DRAM-v to characterize and analyze soil viral communities and their ecological functions. Additionally, R scripts are included to generate figures for data visualization.
