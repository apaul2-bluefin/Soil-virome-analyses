#Virome analysis pipeline 

#SUMMARY

Analyses the metagenome assembled genomes for identification of viral sequences using Virsorter and VITAP, which looks for groups such as dsDNAphage,ssDNA,RNA, and other viral IDs. The viral FASTA files produced by Virsorter2 and VITAP was concatenated into one file and the viral contigs was clustered into viral operational taxonomic units (vOTUs) using CD-Hit.  The combine file with the viral contig clusters was checked for quality using CheckV. CheckV assesses the combined .fa file for genome completeness, contamination, and assigns quality categories (complete, high, medium, or low quality). The quality_summary.tsv file from CHECKv was filtered to jeep the medium-quality and above scores to result in a medium_plus_filtered_votu.fa file that ahs all the good quality clustered viral contigs.

#run virsorter 
virsorter run \
  -i /project/bcampb7/camplab/MICRO_8130_2026/project/working_dir/Control_23_R1_S13.fa \
  -w /project/bcampb7/camplab/MICRO_8130_2026/project/working_dir/virsorter_output \
  --db-dir /project/bcampb7/camplab/MICRO_8130_2026/project/tools/virsorter2_db \
  --min-length 1500 \
  --include-groups "dsDNAphage,ssDNA,RNA,NCLDV,lavidaviridae" \
  -j 16 \
  all

## VITAP

### CD-Hit
module load cd-hit/4.8.1

cd-hit-est \
-i viral_contigs_combined.fasta \
-o vOTUs.fasta \
-c 0.95 \
-aS 0.85 \
-T 20 \
-M 0
